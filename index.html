تنظیمات اتصال هوش مصنوعی

این نسخه برای Ollama Cloud تنظیم شده است. کلید API را در تنظیمات وارد کن. هشدار: کلید در مرورگر ذخیره می‌شود و برای انتشار عمومی مناسب نیست. بدون API هم برنامه در حالت محلی و نمایشی اجرا می‌شود.

هشدار امنیتی: کلید در مرورگر قابل مشاهده است. از این روش روی سایت عمومی استفاده نکن؛ کلید در مرورگر ذخیره می‌شود؛ برای انتشار عمومی از بک‌اند امن استفاده کن.
بک‌اند باید پیام‌ها را دریافت کند و پاسخ متنی را در JSON با فیلد answer یا content برگرداند. کلید را فقط در سرور نگه دار.
