# دستیار فخر اروم — نسخهٔ GitHub Pages

## محتویات
- `index.html`: برنامهٔ اصلی
- `manifest.webmanifest`: اطلاعات نصب‌پذیری وب‌اپ
- `sw.js`: کش فایل‌های اصلی برای باز شدن پوستهٔ برنامه در حالت آفلاین
- `icons/icon.svg`: آیکون برنامه

## انتشار رایگان با GitHub Pages
1. وارد GitHub شوید و یک مخزن جدید بسازید؛ مثلاً `fakhr-orum`.
2. فایل‌ها و پوشه‌های همین بسته را در ریشهٔ مخزن بارگذاری کنید؛ `index.html` باید در ریشه باشد.
3. در مخزن به `Settings` → `Pages` بروید.
4. در بخش Build and deployment، گزینهٔ `Deploy from a branch` را انتخاب کنید.
5. شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و Save کنید.
6. پس از پایان انتشار، آدرس نشان‌داده‌شده در صفحهٔ Pages را باز کنید.

## نصب روی موبایل
پس از انتشار، سایت را در Chrome اندروید باز کنید و از منوی مرورگر گزینهٔ `Install app` یا `Add to Home screen` را بزنید. این کار وب‌اپ نصب‌پذیر می‌سازد؛ هنوز APK مستقل نیست.

## نکات مهم
- رابط کاربری و پوستهٔ برنامه می‌توانند پس از اولین بارگذاری در حالت آفلاین باز شوند؛ چت هوشمند آنلاین بدون اینترنت کار نمی‌کند.
- حالت «محلی» فعلاً پاسخ‌های محدود و نمونه‌ای دارد و مدل زبانی کامل نیست.
- برای استفادهٔ عمومی، کلید API را داخل فایل HTML یا APK قرار ندهید. برای API مشترک باید بک‌اند امن و کنترل مصرف راه‌اندازی شود.
- برای ساخت APK مستقل، پس از انتشار باید دامنه و تنظیمات Trusted Web Activity/Bubblewrap بررسی و تنظیم شود.
